# ISBN Submission

This folder contains all files required for ISBN registration and publication.

Each book folder includes:

- `metadata.md` — Title, subtitle, author, publisher and ISBN information.
- `cover.png` — Final front cover artwork.
- `paperback.pdf` — Print-ready interior PDF.
- `ebook.epub` — EPUB edition.

Once ISBNs are assigned, update the copyright page, regenerate the final editions, and archive the ISBN details in `metadata.md`.
