# VTR Press Release Checklist

Use this checklist for a production publishing release. Items that do not apply to a particular publication may be marked N/A.

## Manuscript

- [ ] Manuscript finalized
- [ ] Manuscript frozen for release
- [ ] Document type confirmed
- [ ] Metadata reviewed
- [ ] Author and contributor information reviewed
- [ ] Copyright information reviewed
- [ ] ISBN / identifier information reviewed, where applicable

## Assets

- [ ] Cover finalized, where applicable
- [ ] Back cover finalized, where applicable
- [ ] Author/about material finalized, where applicable
- [ ] All referenced images and assets available
- [ ] Asset paths and references validated

## Build

- [ ] PDF generated
- [ ] EPUB generated
- [ ] Build completes without errors
- [ ] Generated files contain the expected metadata
- [ ] Output filenames and release directories are correct

## Quality Review

- [ ] PDF visually reviewed
- [ ] EPUB opened and reviewed in an EPUB reader
- [ ] Headings and document hierarchy verified
- [ ] Lists verified
- [ ] Tables verified
- [ ] Code blocks verified, where applicable
- [ ] Images and captions verified, where applicable
- [ ] Page breaks and pagination reviewed for print PDF, where applicable
- [ ] Contents/navigation verified
- [ ] Front matter and back matter verified
- [ ] No unintended blank pages or missing content

## Release

- [ ] Final corrections applied
- [ ] Final PDF regenerated after corrections
- [ ] Final EPUB regenerated after corrections
- [ ] Release artifacts archived
- [ ] Git tag created, where the release process requires one
- [ ] Published to the intended distribution channel(s)
- [ ] Publication availability verified

## Post-Release

- [ ] Released artifacts retained as the release record
- [ ] Repository documentation updated if release behaviour changed
- [ ] Any follow-up issues recorded
